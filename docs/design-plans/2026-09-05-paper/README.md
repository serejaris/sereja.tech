# Бумажный визуальный план

Актуальная версия — `plan.html`. Страница повторяет визуальную систему lesson-guide-writer: фон #fffef9, PT Serif, PT Mono, колонка 740 px, обычное оглавление, последовательные разделы. После H1 и лида стоит inline SVG процесса из шести этапов, затем практический вывод и оглавление. Источник схемы — `transition-diagram.svg`. В каждом разделе изображения стоят рядом: «Было» слева, «Будет» справа. Сравнение расширяется до 1240 px, текст остаётся в колонке 740 px. Макеты открываются обычными ссылками. Доска, табы и модальные окна первой версии убраны по комментарию пользователя.

## Исправления

- В первой версии захват принудительно использовал светлую тему. У пользователя сайт открыт в тёмной. Девять текущих страниц пересняты через CUA в браузере пользователя; для каждой записаны адрес, фон, тема и CSS viewport 1440 × 900 в `browser-baseline-v2.json`.
- Главная содержит видеоплеер перед статьями.
- Обложка стандартного поста находится над заголовком.
- Мобильная проверка пропущена по явному запросу пользователя.

## Состав

Главная, стандартный пост, блог и поиск, фрагмент поста с графиками, автор, ссылки, каталог тем, статьи по теме и 404. В плане 18 кадров по 1440 × 900. Изображения встроены; ссылки ведут к локальным полноразмерным снимкам и HTML-макетам. Для передачи всего пакета сохраните папку целиком. Шрифты и видеоплеер требуют сети.

Обычная статья сохраняет текст, заголовки, обложку и переходы. Поиск макета работает по 121 заголовку. Интерактивная статья показывает только описание модели, три графика и один промпт; полный перенос остаётся задачей реализации.

## Проверено

CUA: колонка 740 px, PT Serif, фон #fffef9, 18 загруженных кадров 1440 × 900, рабочее оглавление, отсутствие переполнения; видеоплеер существует, обложка геометрически выше H1. Результат в `validation-v2.json`.

`check_plan.py` сверяет байты встроенных снимков с файлами источников, размер каждого кадра, существование локальных ссылок и целей оглавления.

```sh
python3 docs/design-plans/2026-09-05-paper/build_plan.py
python3 docs/design-plans/2026-09-05-paper/check_plan.py
```

`build_prototypes.py` сохраняет исходный способ сборки макетов. После изменения макета переснимите его через браузер и пересоберите план. Старые дополнительные кадры и `validation.json` относятся к первой версии; актуальная версия использует только кадры, перечисленные в плане.
