## Расхождения и оговорки аудита

- Проверки шаблонов выполнены на ветке `redesign/home-blog` (2 коммита впереди `origin/main`) — после мержа редизайна нужен продакшен-смоук, особенно шрифты (находка №12).
- PageSpeed Insights API вернул 429 (дневная квота без ключа) — полевые LCP/INP/CLS не получены; выводы по CWV основаны на статическом анализе и живых заголовках. Рекомендуется прогнать PSI с ключом или смотреть CrUX после деплоя редизайна.
- Два аудитора проверяли приоритет `layouts/robots.txt` vs `static/robots.txt` с разным выводом о том, кто побеждает (изолированный тест: layout; наблюдение по mtime: static). Файлы байт-в-байт идентичны, поэтому удаление любого из дублей безопасно при сверке `public/robots.txt` после билда.
- Сравнение GSC 2026-05-03 (indexed 75) и 2026-07-08 (indexed 50) — не строго сопоставимые метрики; требуется свежий экспорт для подтверждения регресса.
