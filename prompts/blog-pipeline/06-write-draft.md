# 06 — Write draft

Пиши только из packet. Не додумывай факты.

```
{{writer packet}}
```

Черновик для sereja.tech (вайбкодеры):

- 1 reader_job, 1 thesis
- evidence только из packet (≤3)
- exclude буквально
- вердикт в первых 150 словах
- ≤1 raw blockquote
- 1 primary CTA из contract
- ≥800 слов (practical_review ≤1500)
- автор «просит агента», не «пишет код сам»
- промпты в callout
- internal links только из related_posts
- frontmatter draft: title, date, description, tags
