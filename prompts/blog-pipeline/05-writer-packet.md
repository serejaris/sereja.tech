# 05 — Writer packet

Единственный вход для черновика. Без full transcript / full research.

**Входы:**
- contract: {{angle contract}}
- evidence: {{≤3}}
- research: {{compact Phase 03}}
- related: {{Phase 04 JSON}}
- voice: {{коротко author-bible / writing-guide}}

Собери packet:

```markdown
### Angle contract
### Evidence (≤3)
### Verified external facts
### Structure outline  # под thesis, не хронология
### Related posts
### Author voice constraints
### Exclude  # полный список
### Self-check  # fact ∉ sources → удалить или BLOCKING
```

**Запрещено в packet:** full transcript, TG-thread, research notebook, backlog angles.

**Выход:** полный packet → issue.
