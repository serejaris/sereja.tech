Архитектор агентных систем на Claude Code. Веду телеграм-канал, YouTube и лучшее сообщество вайбкодеров.

Вайбкодинг

Создание программ без написания кода вручную. Ты описываешь что хочешь, агент (Claude Code, Cursor) пишет за тебя. Фокус на продукте, не на синтаксисе.

Маршруты по задачам

Память и координация

  • GitHub Projects как память для AI-агента — если агент теряет контекст между сессиями и репозиториями.
  • Agent Teams в Claude Code — когда один агент уже не справляется и нужна параллельная команда.
  • Как перестать сжигать контекст Claude Code впустую — где на самом деле утекают токены и как вернуть себе бюджет.

Инструменты и браузер

  • Homebrew для вайбкодинга — базовый CLI-стек, который агент может ставить и обновлять одной командой.
  • Chrome DevTools MCP: настройка с живым браузером — когда агенту нужен доступ к залогиненному Chrome, а не к чистому Chromium.
