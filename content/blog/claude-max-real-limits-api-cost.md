Коротко: Claude Pro за $20 хватает, чтобы попробовать Claude Code. Max 5x за $100 подходит для регулярной работы. Max 20x за $200 нужен при ежедневной высокой нагрузке.

Я использовал все три уровня. Для вайбкодинга рабочий тариф у меня начинается со $100. Подписка за $20 заканчивается слишком быстро. За $200 лимитов больше, но безлимита там тоже нет.

| Подписка | Объём относительно Pro | Для чего подходит |
|---|---:|---|
| Pro, $20 | 1x | Познакомиться с Claude Code |
| Max 5x, $100 | 5x | Регулярно работать над проектами |
| Max 20x, $200 | 20x | Работать каждый день с высокой нагрузкой |

В примерах ниже агент читает файлы, ищет ошибки, вносит правки и запускает тесты. Чтение файлов и вызовы инструментов создают основную часть расхода.

## Какие лимиты входят в подписку

[Claude Pro стоит $20 в месяц](https://support.claude.com/en/articles/8325606-what-is-the-pro-plan). В него входят Claude в браузере, Claude Code и Cowork. Их расход складывается в общий лимит.

У подписки два основных ограничения: пятичасовое и недельное. Anthropic также вводит отдельные лимиты для моделей и функций.

[Max 5x и Max 20x стоят $100 и $200](https://support.claude.com/en/articles/11049741-what-is-the-max-plan). В пятичасовом окне они дают в пять и двадцать раз больше Pro.

20x описывает объём внутри пятичасового окна. Недельный расход зависит от модели, проекта, длины разговора и количества прочитанных файлов.

Anthropic не публикует недельную квоту в токенах. Поэтому я смотрю на свои логи.

[До 19 августа 2026 года недельный лимит Claude Code увеличен на 50%](https://support.claude.com/en/articles/15910845-claude-code-may-august-2026-weekly-limits-promotion).

Пятичасовой лимит остался прежним. Все недельные замеры ниже сделаны до этого повышения.

## Сколько токенов съедает работа

Токенами считаются промпты, ответы, прочитанные файлы и результаты инструментов. Чем дольше живёт сессия, тем больше старого контекста Claude повторно обрабатывает на каждом шаге.

Я разбирал [22 своих сессии Claude Code](https://sereja.tech/blog/claude-code-token-optimization/). За один активный день четыре проекта и 920 вызовов инструментов набрали около 616 тысяч токенов.

Это мои старые логи. Они показывают разницу между задачами без привязки к квоте тарифа.

| Кейс | Пример работы | Реальный расход |
|---|---|---:|
| Один файл | Проверить JWT в одном указанном файле | около 3k токенов |
| Целый проект | Проверить проект на баги без точного указания места | 50-70k токенов |
| Рабочий день | 22 сессии в четырёх проектах | около 616k токенов |

Проверка одного указанного файла заняла около 3k токенов, поиск багов по всему проекту занял 50-70k. Во втором случае агент сделал 15-20 вызовов чтения.

Один точечный вопрос к известному файлу может уложиться в несколько тысяч токенов. Когда агент сначала ищет место ошибки по всему проекту, расход растёт на порядок. В большом рабочем дне таких проходов десятки.

В моём разборе 95,5% контекста приходилось на результаты инструментов. Сильнее всего расход рос из-за чтения файлов и повторной обработки старого контекста.

Для грубой оценки я сначала смотрю на масштаб: агент откроет один файл, прочитает весь проект или будет работать в нескольких проектах весь день. Количество сообщений само по себе мало говорит о расходе.

У презентации нет фиксированного расхода. Число слайдов, объём исходных материалов и количество правок каждый раз разные.

[Claude Design расходует тот же общий лимит](https://support.claude.com/en/articles/14604416-get-started-with-claude-design), что Claude и Claude Code.

Сложные проекты, большие кодовые базы и многочисленные итерации быстрее расходуют общий лимит.

Цифра «презентация стоит миллион токенов» имеет смысл только вместе с логом конкретной работы.

## Что такое ccusage и что означают доллары

[`ccusage`](https://ccusage.com/guide/cost-modes) читает локальные логи Claude Code. Программа складывает входные, выходные и кэшированные токены и показывает, сколько такая же работа стоила бы через API.

Например, сумма $400 означает: при прямой оплате API те же токены стоили бы примерно $400. Подписка при этом остаётся подпиской за $100. Дополнительного списания из-за отчёта нет.

Так логи разных дней можно сравнивать в API-долларах.

`ccusage` видит только локальные сессии Claude Code. Работа в браузере, Claude Design и часть внешних инструментов в такой отчёт не попадают.

## На сколько хватало Max 5x за $100

В одном пятичасовом периоде `ccusage` показал [$40,87 по ценам API](https://t.me/vibecod3rs/30863).

![Пятичасовой расход Claude Max 5x](/images/blog/claude-max-api-cost-5x.webp)

За полную неделю в лимит у меня помещалось [около $400 такой работы](https://t.me/vibecod3rs/38196).

В моём режиме Max 5x хватало для регулярной работы над проектами. Расход всё равно приходилось контролировать, особенно при частом использовании Opus 5 и длинных сессиях.

## На сколько хватает Max 20x за $200

В моём интенсивном периоде на Max 20x [72% недельного лимита ушло за полтора дня](https://t.me/vibecod3rs/57733).

Даже Max 20x у меня закончился бы за несколько дней при таком темпе. Параллельные агенты, Opus 5 и длинный контекст ускоряют расход.

[Внешний тест Botfarm](https://botfarm.run/blog/claude-max-true-price/) по неполной неделе оценил полную недельную ёмкость примерно в $1100 для Max 20x и $523 для Max 5x. Автор называет эти оценки нижней границей.

Botfarm проводил этот тест до выхода Opus 5. Сейчас Opus 5 стоит по умолчанию на Max, поэтому оценки $1100 и $523 остаются историческим ориентиром.

## Какой тариф выбрать

По моему опыту, за $20 можно познакомиться с Claude Code. Отдельного замера Pro в токенах или API-долларах у меня нет, поэтому точное число задач я не обещаю.

У меня регулярная работа начинается с Max 5x за $100. В историческом замере за неделю в него помещалось около $400 по ценам API.

Max 20x за $200 нужен, когда Max 5x тормозит работу почти каждую неделю и дополнительный лимит точно будет занят.

Мой короткий выбор: $20 для знакомства, $100 для работы, $200 для интенсивной работы.
